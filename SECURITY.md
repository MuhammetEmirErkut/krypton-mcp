# Security Policy

We release security patches and bug fixes for the active development versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## 🔒 Reporting a Vulnerability

The KryptonMCP team takes security vulnerabilities seriously. We appreciate the responsible disclosure of security flaws and will work diligently with researchers to resolve identified issues.

### How to Report:
1. **GitHub Private Vulnerability Reporting (Preferred)**:
   - Navigate to the [Security tab](https://github.com/MuhammetEmirErkut/krypton-mcp/security) of the repository.
   - Click on **"Report a vulnerability"** to submit your findings privately.
2. **Email**:
   - If you cannot use GitHub Private Reporting, please email **`muhammetemir.erkut@gmail.com`** with the subject `[VULNERABILITY] KryptonMCP - <Short Description>`.

### What to Include:
- Description of the vulnerability and attack vector.
- Step-by-step reproduction steps or a minimal Proof of Concept (PoC).
- Impact assessment (e.g., PII leakage, bypass of guardrails, credential exposure).
- Any suggested fixes or remediations.

### Our Commitment:
- **Acknowledgement**: We will acknowledge receipt of your report within **48 hours**.
- **Assessment**: We will confirm the issue and provide an estimated timeline for a patch.
- **Credit**: We will credit researchers in our release notes (unless requested to remain anonymous).

> ⚠️ **Important**: Please do **NOT** open public GitHub issues or disclose security vulnerabilities publicly before a fix is released.
